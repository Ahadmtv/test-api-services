# ADR 0006: محیط محلی، آزمون و مستندات

- وضعیت: پذیرفته‌شده برای طراحی MVP

## زمینه

رزرو هم‌زمان، قیدهای PostgreSQL و ثبت مالی را نمی‌توان تنها با mock یا آزمون unit قابل اعتماد سنجید. توسعه‌دهنده باید بتواند رفتار محلی را تکرار کند.

## تصمیم

Docker Compose محیط محلی را برای PostgreSQL و اجزای برنامه فراهم می‌کند. مهاجرت‌ها با فرمان مشخص و نسخه‌بندی‌شده اجرا می‌شوند. unit test برای قواعد دامنه و integration test روی PostgreSQL برای constraint، transaction، idempotency و concurrency نوشته می‌شود. fake payment gateway تمام آزمون‌های خودکار را پشتیبانی می‌کند؛ Sandbox واقعی وابستگی CI نیست. قرارداد OpenAPI 3.1 اعتبارسنجی و به آزمون API متصل می‌شود. مستندات توسعه‌دهنده به فارسی نگهداری می‌شوند و هیچ test result اجرا‌نشده موفق گزارش نمی‌شود.

## پیامدها

- آزمون‌های هم‌زمانی باید DB واقعی هم‌نوع PostgreSQL را داشته باشند.
- Compose و CI بعد از درخواست مرحله راه‌اندازی ساخته می‌شوند؛ این ADR به‌تنهایی کد یا پیکربندی اجرایی ایجاد نمی‌کند.
- اجرای محلی/CI نباید به راز production، provider واقعی یا دسترسی شبکه‌ای غیرضروری وابسته باشد.
